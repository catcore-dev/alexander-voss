# alexander-voss

**Personal portfolio for Elias Renner — fashion & editorial photographer based in Paris/Vienna.**

A cinematic single-page brand site with full-bleed panels, grayscale palette, and warm amber accents. No images needed — the geometric layouts and gradient panels convey the visual language of high-end photography without actual photos.

## Live site

👉 [catcore-dev.github.io/alexander-voss](https://catcore-dev.github.io/alexander-voss/)

## Features

- Full-viewport hero with dramatic serif typography
- Featured work panel with asymmetric grid and stats
- Gallery strip — 6 interactive cards with hover effects
- Client marquee — 8 luxury brand names
- Smooth scroll-linked reveal animations
- Completely grayscale + amber palette — editorial photography aesthetic

## Tech

Single HTML file. CSS custom properties, grid, flexbox, intersection observer for reveal animations. No fonts to load — uses EB Garamond system stack and sans-serif for labels.

---

Portfolio site. No frameworks, no templates.
